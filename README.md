# Pet Shop Recommendation API

Учебный проект по системному анализу (магистратура, модуль 2).
Интернет-магазин товаров для домашних животных с персональными рекомендациями: владелец создаёт профиль питомца, указывает нежелательные ингредиенты и получает подборку товаров с объяснениями.

**Команда:** Копылова Мария, Федяевская Дарья, Боргуль Екатерина.

## Состав репозитория

| Файл / папка | Что внутри |
|---|---|
| `API.ipynb` | Код API, автоматические проверки, выгрузка OpenAPI, запуск сервера |
| `main.py` | Тот же код API в виде скрипта (для запуска без Jupyter) |
| `test_api.py` | 33 автоматические проверки API |
| `export_openapi.py` | Выгрузка спецификации в `openapi.json` и `openapi.yaml` |
| `openapi.yaml`, `openapi.json` | Спецификация OpenAPI 3.1 |
| `docs/` | Итоговый отчёт (.docx) |
| `docs/diagrams/` | Исходники диаграмм PlantUML (`.puml`) и изображения (`.png`) |

## Как посмотреть спецификацию без запуска кода

Откройте [Swagger Editor](https://editor.swagger.io/) → **File → Import file** → выберите `openapi.yaml`.

## Как запустить

Нужен Python 3.10+.

```bash
pip install -r requirements.txt
python main.py
```

Swagger UI откроется по адресу http://127.0.0.1:8000/docs.

Автоматические проверки (сервер запускать не нужно):

```bash
python test_api.py
```

В Jupyter: откройте `API.ipynb` и выполните **Kernel → Restart & Run All**.

## Эндпоинты

| Метод | Путь | Назначение |
|---|---|---|
| GET | `/ingredients` | Справочник ингредиентов |
| GET | `/pets` | Список питомцев |
| POST | `/pets` | Создать питомца |
| PATCH | `/pets/{pet_id}` | Изменить профиль питомца |
| GET | `/products` | Каталог |
| GET | `/products/{product_id}` | Карточка товара |
| GET | `/pets/{pet_id}/recommendations` | Персональные рекомендации |
| GET | `/cart` | Содержимое корзины |
| POST | `/cart/items` | Добавить товар в корзину |
| PATCH | `/cart/items/{item_id}` | Изменить количество |
| DELETE | `/cart/items/{item_id}` | Удалить позицию |
| POST | `/orders` | Создать заказ |
| GET | `/orders/{order_id}` | Получить заказ |
| POST | `/payments/webhook` | Обработать уведомление об оплате |

## Ограничения прототипа

Данные хранятся в памяти и сбрасываются при перезапуске. Авторизации нет: один покупатель и одна корзина. Платёжный сервис — заглушка, уведомление об оплате отправляется вручную через `POST /payments/webhook`.
